# tipis_2 — Авиационная транспортная система

Веб-калькулятор системно-динамической модели характеристик авиационной
транспортной системы (АТС) по критерию безопасности полётов.

## Запуск

Откройте файл `index.html` в любом браузере (двойной клик). Сборка и
интернет не требуются — всё работает локально, без внешних зависимостей.

Если нужно работать через локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

## Интерфейс (один экран, без прокрутки)

- **Меню-бар** сверху — все разделы доступны из выпадающих меню:
  - *Ввод данных* — разделы панели ввода (настройки, начальные условия, факторы, полиномы, фактические данные);
  - *Формулы* — модальные окна: система уравнений (1), полиномы факторов F(t), полиномы f₁…f₃₆, численный метод, о модели;
  - *Результаты* — переключение рабочего области: график / таблица значений / погрешности MAE·СКО·MAPE, экспорт CSV;
  - *Вид* — тёмная тема, сброс настроек.
- **Панель ввода** слева (аккордеоны) — все числовые поля заменены ползунками
  со связанным точным значением (число можно ввести вручную, границы ползунка
  раздвигаются автоматически):
  - настройки: год t₀ (2011), горизонт, шаг интегрирования РК4, ограничение параметров 0…1;
  - начальные условия X(t₀) — значения статистики за t₀;
  - внешние факторы F(t) = (a₀ + a₁t + a₂t²)/масштаб — Price, For, Dol, Covid, Law;
  - полиномы f₁…f₃₆ (f(x) = a₀ + a₁x + a₂x²);
  - фактические данные по годам — сразу показывает MAE, СКО (RMSE), MAPE;
    кнопки «Тест: параметр» / «Тест: все 10» генерируют тестовые ряды
    (модельная траектория + случайный шум ±5%), «Очистить» удаляет данные.
- **Область просмотра** справа: график (Рунге–Кутты 4-го порядка, фактические
  данные пунктиром), таблица значений по годам, таблица погрешностей.

Настройки сохраняются в браузере (localStorage).

## Модель

Источник: Асеев Н.А., Кушников В.А. «Моделирование и прогнозирование
характеристик авиационной транспортной системы для СППР авиационной
безопасности». Модель — 10 нелинейных дифференциальных уравнений системной
динамики (dXпроис/dt … dXповт/dt) с полиномами f₁…f₃₆ и внешними факторами:

- `Price(t) = 0.41 + 0.26t + 0.33t²`
- `For(t) = 87 − 4t − 16t²`
- `Dol(t) = 29 + 100t − 55t²`
- `Covid(t) = −5 + 6t`
- `Law(t) = 21 + 17t − 3t²`

## Структура

```
index.html       — одноэкранная страница (меню-бар, панель, область просмотра)
css/style.css    — строгий математический стиль (serif, тонкие линии, темы)
js/model.js      — параметры, факторы, система уравнений, интегратор Рунге–Кутты 4-го порядка
js/charts.js     — отрисовка графиков на canvas
js/app.js        — интерфейс: меню, панель ввода, виды, модальные окна, погрешности, CSV
```

## Примечания

- Коэффициенты полиномов f₁…f₃₆ в оригинальной работе строятся регрессионным
  анализом статистических данных; по умолчанию принята слабая линейная связь
  f(x) = 0.1x — подставьте свои коэффициенты в панели «Полиномы f₁…f₃₆».
- Факторы нормируются (For, Dol, Covid, Law делятся на 100) и приводятся к
  диапазону 0…1.25.
